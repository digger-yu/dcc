codegen/x86_64: fix static local InitList with &&label

Root cause:
When registering static local variables with InitList initializers,
register_one_static_local() called gen_global_init_list() with
rel=None, preventing &&label expressions from generating data
relocations in ET_REL mode.

This caused static const void *l[] = {&&lab0, &&end} to write
zeros to .data without .rela.data entries, making computed goto
through label address arrays jump to address 0 (segfault).

Fix:
Pass Some((base, None)) to gen_global_init_list() where base is
the current data_section offset, matching the pattern used for
global variables. This allows eval_const_expr() to properly
populate pending_data64_rels for &&label references.

Impact:
Fixes 14 computed goto tests including 920415-1.c, 920501-3.c,
920721-4.c, 20040302-1.c, and other tests using static label
address arrays.
