codegen/x86_64: fix scalar-vector casts via movq

Root cause:
Casting between scalar integers and vectors of the same size
(e.g., (V2SI) 0LL or (long long) vector_var) went through
gen_same_size_bitcast which used a complex memory-copy path
via rep movsb. This path had bugs in source address calculation,
causing segfaults when trying to copy from address 0.

Fix:
Add direct handling for scalar<->vector casts of size <= 8 bytes:
- Scalar to vector: use movq xmm0, rax to move GP register bits
  directly into XMM register low bits
- Vector to scalar: load vector from temp slot 0 into xmm0 via
  movq xmm0, [r13+off], then movq rax, xmm0 to extract low bits

This matches GCC's codegen pattern and avoids the buggy memory
copy path entirely.

Impact:
Fixes basic scalar-vector cast operations. More complex vector
operations may still have issues, but this establishes correct
foundations for the common cast patterns.
