# pr128080 — 256 字节 signed char 向量的 __builtin_shuffle(x, c, m),
# m = {0, -1}, 期望 r[1] == c[255]（拼接向量 {x,c} 的下标 511）。这个期望

#      掩码元素重建成 **ssizetype**（有符号）, 于是常量掩码 -1 走
#      vec-perm-indices.h::clamp 的“负值从尾部数”分支: -1 + 2N = 511;

#      掩码元素类型的 **unsigned 变体** (2026-11-05 PR 128451 的修复):

# 就不成立 —— 属优化能力缺口而非 codegen 缺陷。对照: 同一运行期语义的
